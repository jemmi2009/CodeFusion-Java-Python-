# Contributing to CodeFusion

Thank you for your interest in improving CodeFusion! Here's how to contribute:

## 📋 Before You Start

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`
3. **Make your changes**
4. **Test thoroughly** before submitting

## ✅ Code Standards

### Java
- Use camelCase for variables and methods
- Use PascalCase for class names
- Add Javadoc comments for public methods
- Maximum line length: 100 characters
- Use 4 spaces for indentation

### Python
- Follow PEP 8 style guide
- Use snake_case for functions and variables
- Add docstrings to all functions
- Use 4 spaces for indentation
- Run `black` and `pylint` before committing

## 📝 Commit Messages

Format: `type(module): brief description`

Examples:
- `feat(Functions): add prime number checker`
- `fix(OOP): correct inheritance example`
- `docs(README): update quick start guide`

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`

## 🔄 Submission Process

1. **Push to your fork**
2. **Create a Pull Request** with:
   - Clear description of changes
   - Link to related issues (if any)
   - Example output if applicable

## 📚 Adding New Modules

When adding a new learning module:

1. Create module directory: `java/N_ModuleName/` and `python/N_ModuleName/`
2. Add implementation files
3. Create comprehensive `README.md` with:
   - Theory explanation
   - Code examples
   - Practice exercises
4. Update main `README.md` with new module reference

---

**Thank you for making CodeFusion better!** 🚀
