## 🚀 Quick Start

### Prerequisites
- **Java**: JDK 11+ installed
- **Python**: Python 3.7+ installed

### Running Java Examples

```bash
# Navigate to a Java module
cd java/3_Functions

# Compile
javac BasicMethods.java

# Run
java BasicMethods
```

**Output:**
```
🚀 Welcome to Code Fusion!
Hello, Alice! 👋
10 + 20 = 30
Area: 50.0
Sum: 15
5! = 120
```

### Running Python Examples

```bash
# Navigate to a Python module
cd python/3_Functions

# Run directly
python basic_functions.py
```

**Output:**
```
=== Basic Functions in Python ===

Hello, Alice! 👋
Hello, Bob! 👋

10 + 20 = 30
Area: 50.0
Sum: 15
5! = 120
Is 10 even? True
0°C = 32.0°F
```

## 📖 Module Deep Dives

### 1️⃣ Functions & Methods (`3_Functions/`)
Learn how to write reusable, maintainable code blocks.

**Topics:**
- ✅ Method/Function syntax
- ✅ Parameters and arguments
- ✅ Return types and values
- ✅ Varargs (variable arguments)
- ✅ Method overloading (Java)
- ✅ Recursion patterns
- ✅ Decorators (Python)

**Practice:** Create functions to solve real-world problems

---

### 2️⃣ Object-Oriented Programming (`4_ObjectOrientedProgramming/`)
Master the four pillars of OOP: **Encapsulation, Inheritance, Polymorphism, Abstraction**

**Topics:**
- ✅ Class design and structure
- ✅ Constructors and initialization
- ✅ Getters and setters
- ✅ Access modifiers (public, private, protected)
- ✅ Inheritance hierarchies
- ✅ Method overriding
- ✅ Polymorphic behavior

**Practice:** Build a class hierarchy for real-world entities

---

### 3️⃣ Collections (`5_Collections/`)
Work with modern data structures efficiently.

**Topics:**
- ✅ Arrays and Lists
- ✅ Sets and uniqueness
- ✅ Maps and key-value pairs
- ✅ Iteration patterns
- ✅ Functional operations

**Practice:** Manipulate collections with complex queries

---

### 4️⃣ Data Structures (`6_DataStructures/`)
Understand fundamental algorithms and data structures.

**Topics:**
- ✅ Time and space complexity
- ✅ Linked lists
- ✅ Trees and traversals
- ✅ Sorting algorithms
- ✅ Searching algorithms

**Practice:** Implement and optimize algorithms

---

### 5️⃣ Decorators (`7_Decorators/`)
Learn powerful design patterns for extending functionality.

**Java - Decorator Pattern:**
- ✅ Component interface design

**Practice:** Create custom decorators for your use cases

## 🔗 Comparison: Java vs Python

| Aspect | Java | Python |
|--------|------|--------|
| **Syntax** | Verbose, explicit types | Concise, dynamic typing |
| **Compilation** | Compiled to bytecode | Interpreted |
| **Speed** | Faster execution | Slower but productive |
| **Learning Curve** | Steeper | Gentler |
| **Use Cases** | Enterprise, Android | Data science, scripting |
| **Decorators** | Design pattern (class-based) | Language feature (function-based) |
